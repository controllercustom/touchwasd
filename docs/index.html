Bootloader Mode Instructions


            

                
M5Stack AtomS3

                
    
                    
  1. Connect the AtomS3 to your computer via USB-C
    2. 
                    
  2. Press and hold the side button (the only button on the side)
    3. 
                    
  3. Keep holding for 2 seconds until the green LED inside turns on
    4. 
                    
  4. Release the button
    5. 
                    
  5. The device is now in download mode (green LED indicates bootloader mode)
    6. 
                    
  6. Click Flash Firmware above and select the device in the browser serial prompt
    7. 
                    
  7. After flashing, re-power the device — or tap the side button to reset it — to boot the new firmware
    8. 
                

            


            

                
Generic ESP32-S3 Dev Module

                
    
                    
  1. Connect the board to your computer via USB
    2. 
                    
  2. Press and hold the BOOT button (GPIO0)
    3. 
                    
  3. While holding BOOT, press and release the EN / RST button
    4. 
                    
  4. Release the BOOT button
    5. 
                    
  5. The device is now in download mode
    6. 
                    
  6. Click Flash Firmware above and select the device in the browser serial prompt
    7. 
                    
  7. After flashing, the board auto-resets via RTS/DTR when uploaded through the UART port (USB-UART bridge)
    8. 
                    
  8. If you uploaded via the native USB port instead, RTS/DTR reset does not work — re-power the board to boot the new firmware
    9. 
                

            


            

                
LilyGo T-Dongle-S3

                
    
                    
  1. Connect the T-Dongle-S3 to your computer via USB-C
    2. 
                    
  2. Press and hold the BOOT button (GPIO0) while plugging in the USB cable
    3. 
                    
  3. Release the BOOT button once connected
    4. 
                    
  4. The device is now in download mode
    5. 
                    
  5. Click Flash Firmware above and select the device in the browser serial prompt
    6. 
                    
  6. After flashing, unplug and re-power the device without holding BOOT to boot the new firmware
    7.

About touchWASD

            
Touchscreen WASD/arrow USB keyboard for gaming. Turns a phone or tablet into a directional input device via an ESP32-S3 with native USB HID — no software to install on the host.
